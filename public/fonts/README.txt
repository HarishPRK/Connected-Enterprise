SELF-HOSTED CONNECTED ENTERPRISE FONTS

These files are unmodified Latin WOFF2 builds obtained from Google's official
Google Fonts stylesheet and fonts.gstatic.com delivery service on 2026-10-12.
The stylesheet query is identical to the application's former remote import:
https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500&display=swap

The Google Fonts response uses one file for all four requested Space Grotesk
weights and one file for both requested JetBrains Mono weights. The application
retains separate CSS font-face declarations for the original weight matching.
No glyphs, naming metadata, styles, or font bytes have been modified.
