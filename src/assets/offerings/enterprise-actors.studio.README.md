# Smart Kitchen style cast for Connected Enterprise

The detailed faces, hands, mapped clothes and weighted human surfaces use the
same fitted MakeHuman library as Smart Kitchen. They retain CE's semantic
animation pivots, store coordinates and enterprise prop roots.

See [rebuild, license and validation](../../../scripts/blender/enterprise_people/README.md).
The Blender Cycles proof is `enterprise-actors.studio-proof.png`; the editable
packed project is `scripts/blender/enterprise_people/enterprise-cast.blend`.
The cast has 45 joints per actor, including three phalanges for each finger.
`enterprise-actors.hands-proof.png` shows the exported skin pinching a card;
the adjacent JSON records bind checks and measured pad-contact errors.
