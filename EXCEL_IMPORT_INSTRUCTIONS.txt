HOW TO IMPORT INTO EXCEL:
============================================================

METHOD 1: Quick Import (All Files)
-----------------------------------
1. Open Microsoft Excel
2. Create a new blank workbook
3. For each CSV file below:
   - Go to: Data > Get Data > From File > From Text/CSV
   - Select the CSV file
   - Click "Load" (Excel will auto-detect formatting)
   - Each file will become a separate sheet

4. Rename the sheets to match the file names


METHOD 2: Copy-Paste (Faster)
-----------------------------------
1. Open each CSV file in Notepad or VS Code
2. Copy all content (Ctrl+A, Ctrl+C)
3. In Excel, create a new sheet
4. Paste (Ctrl+V) into cell A1
5. Excel will automatically separate into columns

RECOMMENDED EXCEL FORMATTING:
============================================================

After importing, make it look professional:

1. FREEZE TOP ROW: View > Freeze Panes > Freeze Top Row

2. AUTO-FIT COLUMNS: Select all > Home > Format > AutoFit Column Width

3. ADD FILTERS: Select header row > Data > Filter

4. COLOR-CODE STATUS:
   - Green: Completed / On Track
   - Yellow: In Progress / At Risk
   - Red: Not Started / Blocked

5. FORMAT CURRENCY: Select business value columns > Home > Number Format > Currency

6. ADD CONDITIONAL FORMATTING:
   - For "% Complete" columns: Home > Conditional Formatting > Data Bars
   - For "Risk Score": Color scale (red = high, green = low)

7. CREATE PIVOT TABLES:
   - Insert > PivotTable
   - Summarize tasks by Priority, Owner, or Status
